## ChatGPT-style AI chat overhaul

Goal (user request): remove the AI's "law" (system-prompt guardrails), give ROZZ a
ChatGPT-like UI, make it use tables instead of star bullets, drop em dashes, and
give the model ALL of the user's data so it can answer any query.

### What changed

- **`lib/core/services/ai_service.dart`**
  - New `streamFinancialAssistant()`: token-by-token SSE streaming for GROQ and
    OpenRouter (OpenAI-compatible `stream:true`); Gemini falls back to one
    non-streaming call (different wire format).
  - New pure, testable SSE parser `sseDeltas()` (skips keep-alives, `[DONE]`,
    malformed lines).
  - System prompt rewritten: removed the old guardrails ("Never invent
    transactions…", "relevant ONLY to personal-finance questions…") and replaced
    them with formatting rules — no em dashes, no leading-star lists, prefer
    markdown tables, keep answers skimmable. Prompt still injects the
    device-local date (the model has no clock).
  - Deleted the `isFinancialQuestion()` keyword gate: the chat now always sends
    the full record, so a rephrased money question can't silently lose data.
  - Shared `systemPromptFor()` / `_promptWithContext()` helpers between the
    streaming and non-streaming paths.

- **`lib/features/chat/presentation/pages/chat_rozz_page.dart`**
  - ChatGPT-style layout: narrow centered column (max 640), user messages
    right-aligned in a soft bubble, assistant answers plain and full-width.
  - Assistant answers render as rich markdown (tables, bold, code) via
    `flutter_markdown_plus`, with a copy button underneath.
  - Live streaming: raw streamed text with a blinking gold caret, stop button
    (replaces the send button) to halt mid-answer, typing-dots bubble while the
    first token is on its way.
  - Empty state: greeting + suggestion chips ("how much did I spend this
    month?", "what's my MAB right now?", …) that fill and send.
  - Context builder now sends the FULL transaction ledger (was: top 15, gated)
    plus month summary, categories, income, recurring income, subscriptions,
    upcoming charges, and the MAB forecast.
  - PII redaction (UPI ids, phones, refs, balances) still applies before
    anything leaves the device — handled in `AiService` when the request body is
    built.

- **`pubspec.yaml`**: added `flutter_markdown_plus ^1.0.12` (plain
  `flutter_markdown` is discontinued).
